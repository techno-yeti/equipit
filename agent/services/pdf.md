# PDF Generation Service

**File:** `pdf.service.js`

## Function: `generateRequestPDF(request, equipmentTypes, createdByUser, fulfilledByUser, depotSite, boxNumber, bayNumber, fulfillmentDate)`

### Dependencies

- **PDFKit** — Document generation library for creating PDFs programmatically
- **qrcode** — Library to generate QR code images from text strings

### Output

- **Directory:** `src/uploads/pdfs/`
- **Filename:** `request-{requestNumber}.pdf`
- **Returns:** `Promise` resolving to `{ filename, filePath }`

### Workflow

1. Generate a QR code image using the `qrcode` library from the request's `requestNumber`
2. Instantiate a new PDFKit document (A4 portrait: 595 × 842 points)
3. Write the following layout to the document
4. Pipe the document to a write stream at the output path
5. Resolve with `{ filename, filePath }` on completion

### PDF Layout (A4 Portrait — 595 × 842 points)

#### Page Background
- **Black bar** spanning full width at the **top** of the page (approx. 15pt height)
- **Black bar** spanning full width at the **bottom** of the page (approx. 15pt height)

#### Header Section
- **"EQUIPIT"** — Large, bold title text
- **"Warehouse Equipment Management"** — Smaller subtitle beneath the title
- **"DISPATCH ADVICE NOTE"** — Section heading clearly indicating document type

#### Details Section (two-column layout)

**Left Box — Request Details**
| Field           | Value                        |
|-----------------|------------------------------|
| Request Number  | `request.requestNumber`      |
| Status          | `request.status`             |
| Supplier        | `request.supplier`           |
| Template        | `request.template` (name)    |
| Depot Site      | `depotSite` (name)           |

**Right Box — Fulfillment Details**
| Field            | Value                          |
|------------------|--------------------------------|
| Created By       | `createdByUser` (name)         |
| Date Created     | `request.createdAt`            |
| Fulfilled By     | `fulfilledByUser` (name)       |
| Fulfillment Date | `fulfillmentDate`              |
| Box Number       | `boxNumber`                    |
| Bay Number       | `bayNumber`                    |

#### Equipment Allocation Table

| # | Equipment Name          | Quantity |
|---|-------------------------|----------|
| 1 | (equipment name 1)      | (qty 1)  |
| 2 | (equipment name 2)      | (qty 2)  |
| … | …                       | …        |

- Alternating row colors for readability
- Row numbers (1-based) in the first column
- Equipment names resolved from `equipmentTypes` lookup
- Quantities from `request.equipments`

#### Authorisation Section

- **"Authorised By:"** label with a signature line (underscore)

#### QR Code Section

- Rendered QR code image for gate scanning
- Request number text displayed adjacent to/beneath the QR code

#### Footer

- **"Generated by Equipit on [current date]"** disclaimer text
- Positioned above the bottom black bar
